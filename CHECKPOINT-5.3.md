# PR 5.3 checkpoint — 20 extracted `objectives` sections

The plan puts a human checkpoint here: read 20 of these before PR 5.4. The question to hold in mind is **"is this the programme's own description of what it funds?"** — not whether the formatting is tidy. If a section is boilerplate, a table of contents, or another programme's text, that is a sectioning bug worth stopping for.

One row per agency, so these span 20 different funders rather than 20 notices from one. 29 rows were tried to find 20 with an `objectives` block; the rest had no attachment or no recoverable structure and fall through to the synopsis. Text is the **longest** `objectives` block per notice, truncated at 1,100 characters.
